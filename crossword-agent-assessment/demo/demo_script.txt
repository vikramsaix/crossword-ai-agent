Hello, and thanks for joining. This is a crossword-solving agent designed for transparent, testable decisions. It converts the grid into numbered entries, requests ranked answer candidates from a configurable language model, then enforces answer lengths and shared crossing letters. Arc consistency removes incompatible guesses; bounded backtracking handles cases that need search. In this demo, eight entries form a complete grid. On a seeded, synthetic benchmark, the top-choice baseline solved none of twenty-two puzzles; the constraint solver recovered all twenty-two. That measures constraint recovery, not real-world clue accuracy. The next evaluation step is a held-out crossword set with live-model accuracy, latency, token use, and cost. The model layer stays provider-neutral.
